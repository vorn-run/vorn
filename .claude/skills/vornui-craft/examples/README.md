# Examples

Do/don't pairs for vornui work. The `vorn-components` gallery does not exist
yet, so each pair is described precisely enough to build and render. When the
gallery lands, render each pair as two small PNGs (`<topic>-do.png`,
`<topic>-dont.png`, 2× scale, ≤ 480 px wide) next to these files and link
them from the pair.

| File                   | Pairs                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------- |
| `motion.md`            | hover fade, press, menu entrance, interrupting, panels, reduce motion                 |
| `surfaces.md`          | buttons and colour, layering and shadows, radius, focus ring, layout shift, alignment |
| `copy.md`              | labels, errors, empty states, confirmations                                           |
| `animation-capture.md` | how to capture a frame strip for a PR                                                 |

Every value below is in logical pixels at 1× unless stated, on
`SURFACE_BASE` (#0d0d0f).
